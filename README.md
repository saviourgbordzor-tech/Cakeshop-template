# Msrich Cakes & Pastries — Custom Ordering Web App

A premium, mobile-first web application built for **Msrich Cakes & Pastries (Ho, Ghana)**. 

This is not a standard template. It is a custom-built, high-conversion digital storefront designed to streamline the bakery's ordering process, showcase their premium event cakes, and automate their WhatsApp orders.

## ✨ Key Features

*   **Live Cake Configurator:** A custom JavaScript-based calculator that allows customers to build their perfect cake (Size, Flavour, Icing, Add-ons) and see the price update in real-time.
*   **Automated WhatsApp Checkout:** Instead of sending 20 messages back and forth, the app automatically formats the customer's entire cart (including cake details and special messages) into a clean, itemized receipt and sends it directly to the bakery's WhatsApp.
*   **Quick-Add Pastries:** A fast-tap interface for their daily pastries (Meat pies, Spring rolls, Bento boxes) with a sticky cart total.
*   **Signature Packages:** Dedicated sections for their high-ticket promo bundles (e.g., Valentine's, Mother's Day).
*   **Dual Theme (Cinematic UI):** A fully responsive, luxurious "Midnight Chocolate" dark mode and an elegant "Coffee & Cream" light mode, complete with 3D background elements and scroll animations.
*   **Live Open/Closed Status:** Automatically checks the local time in Ho to tell customers if the bakery is currently open or closed.
*   **Zero Hosting Costs:** Deployed entirely on GitHub Pages. No monthly server fees.

## 🛠 Tech Stack

*   **HTML5** (Semantic structure)
*   **CSS3** (Custom properties, Flexbox/Grid, animations, responsive design)
*   **Vanilla JavaScript** (No libraries or frameworks, ensuring lightning-fast load times on slow mobile networks)
*   **WhatsApp API** (Deep linking for automated checkout)

## 🚀 How to Use

1. Clone this repo or download the `index.html` file.
2. Open the file in any web browser.
3. To connect it to a different WhatsApp number, simply update the `WA_PHONE` variable inside the `<script>` tag at the bottom of the file.
